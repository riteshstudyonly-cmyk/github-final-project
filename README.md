# simple-interest-calculator


## Project Description
This project is a simple interest calculator implemented using a Bash script. It calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual rate of interest
- Time period in years

## Purpose
This project demonstrates basic Bash scripting and simple mathematical calculations.
